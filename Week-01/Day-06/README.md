Day 6 - Introduction to Wireshark

Objective

Learn how to capture network traffic using Wireshark, identify network protocols, and analyze DNS packets using display filters.

Topics Learned

- Introduction to Wireshark
- Network Interfaces
- Packet Capture
- Packet List Columns
- Source & Destination IP
- Protocol Column
- DNS Queries
- DNS Responses
- Display Filters
- DNS Filter

Practical Work

- Selected the correct network interface (wlp1s0)
- Captured live network traffic
- Observed TCP, UDP, DNS, TLS 1.3 and QUIC packets
- Applied the DNS display filter
- Analyzed DNS queries and responses
- Identified source and destination IP addresses
