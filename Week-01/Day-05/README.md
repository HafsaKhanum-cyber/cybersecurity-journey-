Day 5 - DNS Fundamentals

Objective

Understand how the Domain Name System (DNS) works, how domain names are translated into IP addresses, learn common DNS record types, and perform basic DNS investigations using Linux tools.

---

Topics Learned

- What is DNS?
- Why DNS Exists
- DNS Resolution Process
- DNS Cache
- DNS Resolver
- Root DNS Server
- Top-Level Domain (TLD) Server
- Authoritative DNS Server
- DNS Record Types
  - A Record
  - AAAA Record
  - MX Record
  - CNAME Record
  - NS Record
  - TXT Record
- DNS Spoofing
- DNS Cache Poisoning
- DNS Tunneling (Introduction)

Practical Work

Today I:

- Used `nslookup` to resolve domain names.
- Used `dig` to perform detailed DNS lookups.
- Identified the ANSWER SECTION in a `dig` response.
- Found the IPv4 address returned by an A record.
- Learned how DNS cache speeds up future requests.
- Understood the complete DNS resolution process from browser to authoritative server.
- Learned how DNS can be abused in cyber attacks.
