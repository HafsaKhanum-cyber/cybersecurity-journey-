Day 12 – Linux Users, Groups & File Permissions

Objective

Learn how Linux users, groups, file ownership, and permissions control access to files and directories.

Topics Learned

- Linux Users
- Linux Groups
- File Ownership
- File Permissions
- Read, Write, Execute
- chmod
- chown
- Permission Numbers
- Linux Security

Practical Work

- Used `whoami` to identify my current user
- Used `groups` to view my user groups
- Created a test directory and file
- Used `ls -l` to view file ownership and permissions
- Practiced changing permissions with `chmod`
- Learned how permission numbers work
- Learned the purpose of `chown`
- Investigated a file permission scenario from a SOC Analyst perspective

Key Takeaways

- Linux uses users and groups to manage access.
- Files have an owner and a group.
- Permissions control who can read, write, or execute a file.
- `r` means read, `w` means write, and `x` means execute.
- `chmod` changes file permissions.
- `chown` changes file ownership.
- Incorrect permissions can create security risks.
