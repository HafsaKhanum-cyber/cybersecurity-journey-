Day 10 – HTTP & HTTPS Fundamentals

Objective

Learn how websites communicate using HTTP and HTTPS, understand HTTP requests and responses, explore common HTTP methods and status codes, and analyze web traffic using Browser Developer Tools.

Topics Learned

- HTTP
- HTTPS
- HTTP Request
- HTTP Response
- HTTP Methods (GET, POST, PUT, DELETE, PATCH)
- HTTP Status Codes
- Browser Developer Tools
- Network Tab
- Web Traffic Analysis

Practical Work

- Opened Browser Developer Tools
- Used the Network tab to inspect web requests
- Visited websites and analyzed HTTP/HTTPS traffic
- Identified request methods and status codes
- Observed request and response details
- Captured encrypted web traffic in Wireshark
- Solved a basic SOC investigation scenario

Key Takeaways

- HTTP is used to transfer web content between a browser and a server.
- HTTPS secures communication using TLS encryption.
- HTTP requests are sent by the client, and responses are returned by the server.
- GET retrieves data, while POST sends data to the server.
- Status codes help identify whether a request was successful or if an error occurred.
- Browser Developer Tools are useful for analyzing website traffic and troubleshooting web issues.
