Day 11 – TLS, SSL & Digital Certificates

Objective

Learn how HTTPS protects communication using TLS, understand digital certificates, public and private keys, and inspect a real website certificate.

Topics Learned

- SSL
- TLS
- HTTPS Encryption
- Public Key
- Private Key
- Digital Certificates
- Certificate Authority (CA)
- TLS Handshake
- Certificate Validation

Practical Work

- Used OpenSSL to inspect a website's TLS connection
- Identified the TLS version
- Examined the certificate issuer
- Examined the certificate subject
- Viewed certificate information in a web browser
- Investigated a basic certificate security scenario

Key Takeaways

- SSL is an older protocol and has been replaced by TLS.
- TLS protects data exchanged between a browser and a website.
- Digital certificates help verify a website's identity.
- Certificate Authorities issue and sign trusted certificates.
- Public and private keys are used as part of public-key cryptography.
- The TLS handshake establishes the secure connection before encrypted communication begins.
- Certificate problems can cause browser security warnings.
