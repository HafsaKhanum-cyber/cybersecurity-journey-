Day 9 – Advanced Nmap Scanning

Objective

Learn different Nmap scan types, understand how they work, compare their differences, and think like a SOC Analyst while analyzing scan results.

Topics Learned

- TCP Connect Scan (-sT)
- SYN Scan (-sS)
- Ping Scan (-sn)
- Host Discovery
- TCP Three-Way Handshake
- Stealth Scanning
- Scan Comparison
- SOC Analyst Investigation

Practical Work

- Performed a TCP Connect Scan on localhost
- Performed a SYN Scan using sudo
- Performed a Ping Scan on my local network
- Compared scan results
- Identified active hosts on my network
- Learned why different scan types are used

Key Takeaways

- TCP Connect Scan completes the full TCP Three-Way Handshake.
- SYN Scan sends only the SYN packet and is considered a stealth scan.
- Ping Scan is used to discover live hosts without scanning ports.
- Different scan types serve different purposes depending on the situation.
- SOC Analysts use Nmap to identify hosts, services, and potential security risks.
